# Product Documentation

This section explains who Corex AgentOS is for and what they can do with it.

## Documents

- [Personas and Use Cases](personas-and-use-cases.md) describes human and
  machine users, their goals, and representative workflows.
- [Complete Capability Catalog](capability-catalog.md) lists platform
  capabilities by functional area and roadmap release.
- [Roles and Permissions](roles-and-permissions.md) proposes the access model
  for users, service accounts, workers, and approvers.

## Availability labels

- **Initialized:** repository or application shell exists, but the capability
  is not functional.
- **v0.1-v1.0:** planned for the named roadmap release.
- **Beyond v1.0:** intentionally outside the initial production scope.
- **Integration-dependent:** possible only when the required external model,
  tool, MCP server, data source, or identity provider is connected.

The current repository is in initialization and v0.1 foundation development.
Most capabilities described in this section are target behavior, not currently
available product functionality.
